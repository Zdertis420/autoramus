# Data Model: Без ненужных двойных пересечений

Новых сущностей во входном языке, в IR и в файле нет. Меняется один выбор
внутри разведения по каналам — в какую сторону отходит заявка.

## Заявка (claim, существующая)

Все точки одной стрелки на одной линии; единица разведения (фича 009).
Закреплённые не двигаются; прочие идут в порядке документа.

## Выбор полосы

| Шаг | Кандидаты | Как выбирается |
|---|---|---|
| 0 | каноническая линия | свободна — берётся без оценки |
| k = 1…maxChannels | `канон + k·шаг`, `канон − k·шаг` | из свободных — меньше пересечений; при равенстве — `+` |

Первый шаг, на котором свободна хоть одна сторона, и решает; дальше не ищется.

## Пересечение

| Что | Правило |
|---|---|
| где | горизонталь одной стрелки проходит строго внутри вертикали другой |
| чьё | стрелки разных потоков одной диаграммы |
| стрелка | все сегменты потока на диаграмме, включая ветки дерева |
| касание концами | не пересечение |

## Лишнее пересечение

Пара стрелок, у которой обмен двух соседних параллельных внутренних отрезков
(по одному от каждой, в пределах двух шагов канала, с общей протяжённостью)
уменьшает число их взаимных пересечений.

## Инварианты

| Инвариант | Откуда |
|---|---|
| лишних пар на наборе нет | FR-002, SC-001 |
| пересечений на документе не больше, чем до фичи | FR-003, SC-003 |
| заявка на свободном каноне не двигается | FR-004 |
| при равенстве — прежний выбор `+шаг` | FR-007 |
