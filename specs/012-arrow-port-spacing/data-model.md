# Data Model: Стрелкам у блока — место

Новых сущностей во входном языке, в IR и в файле нет. Меняется то, какие
**значения** раскладка кладёт в уже существующие поля `ir.FunctionLayout`:
`width`, `height`, `x`, `y`. Всё ниже — внутренние величины пакета `layout`.

## Спрос блока

Число мест на каждой стороне одного блока на одной диаграмме.

| Поле | Смысл |
|---|---|
| диаграмма | владелец диаграммы; пусто — контекстная A-0 |
| работа | чей блок |
| вход, выход, управление, механизм | число мест на стороне |

* Источник — `arrows(m)` и раздача мест `assignSlots` (research Р-1). Место —
  поток на стороне, а не сегмент.
* Один и тот же блок на диаграмме родителя и на своей собственной — два разных
  спроса: ключ включает диаграмму.
* Блок, к стороне которого стрелок нет, имеет спрос ноль и не растёт.

## Размер блока

| Поле | Правило |
|---|---|
| базовая ширина, высота | сегодняшние: 72 × 50.4, при десяти и более работах — сжатые `size(stepX)` |
| ширина | `max(базовая, (max(управление, механизм) + 1) · portGap)` |
| высота | `max(базовая, (max(вход, выход) + 1) · portGap)` |

* `portGap = 15` — решение, а не мера (research Р-3).
* Промежуток между соседними стрелками стороны — `длина / (n + 1)`, не меньше
  `portGap` по построению.
* Размер, заданный автором (`width`, `height`), главнее и не меняется;
  незаданный — дописывается по правилу (research Р-8).

## Место на лестнице

| Поле | Правило |
|---|---|
| протяжённость по x | `(n − 1) · stepX + базовая ширина` — сегодняшняя |
| протяжённость по y | `(n − 1) · stepY + базовая высота` — сегодняшняя |
| промежуток по x | `(протяжённость − Σ ширин) / (n − 1)`, но не меньше `gap` |
| подъём от блока i к i+1 | `высота_i + (протяжённость − Σ высот) / (n − 1)`, но не меньше `gap` |
| x первого, y первого | `(80, 80)` |

* Суммы берутся по автоматическим размерам всех блоков диаграммы, включая
  авторские (research Р-8).
* При равных размерах всё совпадает с сегодняшней лестницей до знака.
* Единственный блок диаграммы — в центре листа, растёт симметрично.

## Инварианты

| Инвариант | Откуда |
|---|---|
| промежуток на стороне не меньше 15, кроме блоков с авторским размером | FR-001, FR-009 |
| ось без тесноты — прежнего размера | FR-006 |
| соседние по лестнице блоки не пересекаются: горизонтальный промежуток ≥ `gap` | FR-007 |
| лестница возрастает по обеим осям | FR-007 |
| на наборе все блоки внутри листа A4 | SC-004 |
| документ без тесноты даёт тот же файл побайтово | SC-003 |
