# Quickstart: проверка хода конца в узле

## Предварительно

```bash
cd ramusc && make build     # даст ./ramusc/ramusc
```

Ramus нужен **только на последнем шаге**. Всё, что ему предшествует, меряется по
собранному файлу.

## 1. Посмотреть, что стоит у концов сегодня

```bash
./ramusc/ramusc examples/chakhokhbili.yaml -o /tmp/m.rsf
python3 specs/011-junction-orientation/evidence/ptype.py /tmp/m.rsf
```

Печатает разбивку точек: где точка стоит в ломаной, на чём сидит её конец, куда
уходит отрезок и что записано в `POINT_TYPE`.

**Ожидаемо до фичи**: `-1` у всех 229 точек, включая 66 узловых концов.
**Ожидаемо после**: `0` или `1` у всех 66 узловых концов, `-1` у остальных.

## 2. Сверить с образцом

```bash
python3 specs/011-junction-orientation/evidence/ptype2.py examples/тест.rsf
```

Печатает узлы по одному: какие сегменты в них сходятся, куда уходят и что у них
записано. Так выглядит правильно:

```
узел 46 @(107.3, 45.4): 6:кон/V/PT=1, 75:нач/V/PT=1, 77:нач/H/PT=0
```

Тот же скрипт на нашем файле обязан давать такие же тройки — с номерами наших
узлов и нашими координатами.

## 3. Проверить возврат формы ветвления

```bash
./ramusc/ramusc decompile /tmp/m.rsf --json > /tmp/m.json
python3 specs/011-junction-orientation/evidence/crowd.py
python3 specs/011-junction-orientation/evidence/rawcross.py /tmp/m.rsf
```

**Ожидаемо после отката** на `chakhokhbili`: 73 отрезка, 206 пересечений,
суммарная длина 12427 — значения до фичи 010. Больше — откат неполон.

Эти числа не цель, а отметка возврата: хорошим рисунком они не были и до 010.

## 4. Тесты

```bash
cd ramusc && make check      # форматирование, go vet, все тесты
go test ./internal/generate/ -run TestJunctionEndsCarryOrientation
```

| Тест | Что требует |
|---|---|
| `TestJunctionEndsCarryOrientation` | у каждого конца-узла записан ход и он совпадает с направлением; у прочих точек `-1` |

Тест живёт в `internal/generate`, а не в `layout`: поле пишет генератор, и
проверять надо то, что доехало до файла.

**Порядок работ**: тест пишется первым и обязан покраснеть на 66 концах — до
того, как тронут генератор.

## 5. Убедиться, что ничего не сломалось

```bash
cd ramusc && go test ./...
git diff --stat ramusc/testdata/golden/    # обязано быть пусто
```

## 6. Глазами — и это решающий шаг

```bash
./ramusc/ramusc examples/chakhokhbili.yaml -o examples/chakhokhbili.rsf
```

Открыть в Ramus и посмотреть на любое ветвление: линии обязаны выглядеть
**соединёнными** — общая линия проходит через узел, отвод от него отходит.

Этот шаг решающий, потому что вся фича стоит на гипотезе: незаполненный ход и
есть причина того, что линии выглядят лежащими рядом. Гипотеза опирается на 84
измеренных конца у Ramus, но проверяется только здесь.

**Если картинка не изменилась — гипотеза опровергнута.** Тогда надо сказать это
прямо и вернуться к трём другим измеренным кандидатам (размер блока под число
стрелок, длина линий, расстановка подписей), а не подкручивать поле дальше.
