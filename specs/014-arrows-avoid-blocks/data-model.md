# Data Model: Стрелка никогда не идёт сквозь блок

Новых сущностей во входном языке, в IR и в файле нет. Меняются значения:
точки маршрутов, которым нужен обход; координаты авто-блоков, налезавших на
авторские. Новое в выводе — один код диагностики уровня `warning`.

## Блок-препятствие

| Поле | Смысл |
|---|---|
| прямоугольник | x, y, ширина, высота блока на диаграмме |
| чей | авторский (из `layout.functions`) или расставлен раскладкой |

* Для стрелок препятствие — любой блок своей диаграммы.
* Для расстановки авто-блоков препятствие — авторские блоки и уже поставленные
  авто-блоки этой диаграммы.
* Касание стороны — не пересечение: точка крепления лежит на стороне, линия
  вдоль стороны её не пересекает.

## Кандидат маршрута

| Порядок | Вид | Точек |
|---|---|---|
| 1 | прежний шаблон категории | 2–6 |
| 2 | тот же шаблон с полосой из `lanes()`, ближайшей к прежней | тот же |
| 3 | обход через коридор над всеми блоками | 5–6 |
| 4 | обход через коридор под всеми блоками | 5–6 |

Берётся первый чистый. Кандидат 3 или 4 чист всегда в лестнице без авторских
блоков (research И2).

## Сдвиг авто-блока

| Правило | Значение |
|---|---|
| когда | авто-блок налезает на авторский или на уже сдвинутый авто-блок |
| куда | вправо: за правый край помехи + `blockClearance` |
| если за листом | вниз: за нижний край помехи + `blockClearance` |
| если и так за листом | названная граница: блок остаётся на ступени |
| `blockClearance` | 24 = 4 · `gap` (решение) |

## Предупреждение `arrow_through_block`

| Поле | Значение |
|---|---|
| severity | `warning` |
| code | `arrow_through_block` |
| path | путь первой точки отрезка, идущего сквозь блок |
| line / column | позиция этой точки в документе |
| message | стрелка, диаграмма, работа, сквозь которую она идёт |

* Выдаётся только для авторских сегментов (`layout.arrows`), и не больше
  одного на сегмент.
* Код возврата не меняет: `warning` сборку не останавливает.

## Инварианты

| Инвариант | Откуда |
|---|---|
| ни один отрезок, проложенный раскладкой, не проходит сквозь блок | FR-001, FR-002 |
| чистый маршрут не меняется | FR-003 |
| авто-блоки не перекрывают авторские | FR-010 |
| авторские координаты не меняются | FR-006 |
| авторская стрелка сквозь блок — ровно одно предупреждение на сегмент | FR-011 |
