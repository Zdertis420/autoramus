# Implementation Plan: Раскладка блоков — координаты без ручного `layout`

**Branch**: `005-block-layout` | **Date**: 2026-09-10 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/005-block-layout/spec.md`

## Summary

Компилятор перестаёт требовать от автора координаты. Появляется пакет, который
получает модель без геометрии и отдаёт её же с геометрией: блоки каждой
диаграммы расставляются по диагонали ровно так, как это делает сам Ramus.

Формула не изобретена, а измерена: диагональ от `(80, 80)` до `(660, 322)`,
равный шаг, блок `72 × 50.4`. Совпадение с `тест.rsf` — точное, до последнего
знака.

Стрелки не раскладываются: генератор их не пишет, и вычислять маршруты было бы
производством того, что некому записать.

Разведка нашла одну дыру в спецификации и закрыла её числом: требование «блоки
не накладываются ни при каком числе работ» с фиксированной диагональю
невыполнимо. Порог посчитан — до девяти блоков запас есть, с десяти нужно
уменьшать блок, с двадцати шести не спасает и это. FR-003 переписан с границей.

## Technical Context

**Language/Version**: Go 1.26, модуль `github.com/Zdertis420/autoramus/ramusc`

**Primary Dependencies**: не добавляются. Раскладка — арифметика и сортировка;
солверы ограничений и графовые библиотеки конституцией прямо запрещены

**Storage**: не касается. Пакет не знает ни про ZIP, ни про XML

**Testing**: `go test ./...`; сверка с `тест.rsf` — моделью, которую Ramus
разложил сам; регрессия на `ИзготовлениеЮбки.rsf` — что ручные координаты
побеждают

**Target Platform**: CLI, три платформы; чистая арифметика, платформенно-нейтрально

**Project Type**: компилятор/CLI

**Performance Goals**: не предъявляются. Крупнейшая известная диаграмма — четыре
блока; топологическая сортировка на таких размерах бесплатна

**Constraints**: детерминированность (одни и те же координаты при любом числе
запусков); документ с полной секцией `layout` даёт тот же файл побайтово;
поведение `validate`, `dump`, `decompile` не меняется

**Scale/Scope**: один новый пакет, ~250 строк, вызов в одном месте ветки
компиляции

## Constitution Check

*GATE: пройден до Phase 0 и перепроверен после Phase 1.*

| Принцип | Как соблюдается |
|---|---|
| **I. Единый источник логики** | Раскладка живёт в `ramusc`. GUI получит готовый файл тем же вызовом |
| **II. Ошибки — данные, а не текст** | Новых кодов диагностики не заводится: раскладка получает уже проверенный документ и ошибок автора не порождает. Отказ «нет координат» **исчезает** — причины для него больше нет (FR-009) |
| **III. Детерминированный вывод** | Порядок блоков — стабильная сортировка по документу, не обход map. Координаты — арифметика без плавающей неопределённости в порядке действий. Проверка: два прогона дают одинаковые числа, две сборки — одинаковые байты |
| **IV. Строгий разбор и лесенка конвейера** | Раскладка встаёт ровно на своё место в конвейере: после валидатора, до генератора. Вход — IR без геометрии, выход — IR с геометрией; про XML и ZIP не знает. Оверрайды `layout` применяются **поверх** её результата — как и записано в конституции |
| **V. Эталонные тесты и сверка с реальными файлами** | Формула снята с настоящего файла, а не сочинена. Совпадение с `тест.rsf` проверяется числами, а не на глаз |

Отдельно про запреты конституции: force-directed, Sugiyama целиком и солверы
ограничений не используются. Порядок блоков — топологическая сортировка с
разрывом обратных рёбер; это идея упорядочивания внутри слоя, прямо разрешённая.

Нарушений нет; раздел Complexity Tracking пуст и удалён.

**Оговорка, принятая осознанно.** Формула наблюдалась при `n = 4` и подтверждена
двумя точками при том же `n`. Поведение Ramus для другого числа блоков не
измерялось: равномерный шаг по той же диагонали — обобщение. Это ослабление
принципа V, и компенсируется оно тем, что обобщение записано в допущениях явно, а
не выдано за факт.

**Structure Decision**: заводится ровно один новый пакет — `internal/layout`,
предусмотренный архитектурой с самого начала и до сих пор пустой. Деление внутри
по проходам, а не по сущностям: у раскладки проходы и есть сущности, и каждый
тестируется отдельно (`CLAUDE.md`, раздел «Раскладка»).

Отказ «нет координат» из генератора **не убирается**: раскладка обязана заполнить
всё, и если что-то осталось пустым, это её дефект. Проверка на месте — дешёвая
страховка от тихой записи блока в точку `(0, 0)`.

## Порядок работ

Ступенями; каждая проверяема без следующей.

1. **Размещение.** Диагональ, шаг, размер, сжатие при тесноте, вырожденные
   случаи. Проверка: четыре блока совпадают с `тест.rsf` до последнего знака.
2. **Порядок.** Рёбра из связей, топологическая сортировка, разрыв обратных,
   устойчивость при равенстве. Проверка: на `skirt.yaml` порядок совпадает с
   объявленным; перестановка объявлений при тех же связях ничего не меняет.
3. **Диаграммы.** Раскладка по диаграммам: у каждого родителя своя диагональ.
   Проверка: вложенная модель раскладывается по уровням.
4. **Оверрайд.** Заполняется только отсутствующее. Проверка: документ с полной
   геометрией проходит раскладку без единого изменения.
5. **Обвязка.** Вызов в ветке компиляции. Проверка: `skirt.yaml` компилируется,
   `ИзготовлениеЮбки` даёт тот же файл побайтово.
6. **Документы.** `CLAUDE.md` — числа раскладки и состояние пакетов.

Ступени 1–4 не трогают CLI и закрываются тестами пакета. Ступень 5 меняет
пользовательский контракт: отказ «нет координат» перестаёт возникать.

## Риски

| Риск | Что делаем |
|---|---|
| Формула верна только для `n = 4` | Записано в допущениях; проверка совпадения — именно на `n = 4`, где есть эталон. Для прочих `n` проверяются свойства (равный шаг, лист, отсутствие наложения), а не числа |
| Ramus откажется рисовать блоки, размер которых мы сжали | Сжатие включается с десяти блоков на диаграмме — за каноном IDEF0. Проверка человеком делается на обычной модели |
| Оверрайд заденет порядок записей и сломает побайтовость | Отдельная ступень и отдельная проверка: документ с полной геометрией обязан пройти раскладку без изменений |
| Топологическая сортировка зациклится на обратной связи | Обратные рёбра разрываются явно; проверка на модели с обратной связью обязательна |
| `page` не `A4` | Лист считается тем же; записано как допущение. Другие размеры не наблюдались и в языке пока ничем не отличаются |
