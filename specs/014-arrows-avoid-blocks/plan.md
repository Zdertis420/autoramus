# Implementation Plan: Стрелка никогда не идёт сквозь блок

**Branch**: `Минимальное-расстояние-между-стрелками` | **Date**: 2026-09-26 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/014-arrows-avoid-blocks/spec.md`

## Summary

Три источника «сквозь блок» — три работы:

1. **Обход в раскладке.** Маршруты прямых связей, выходов к краю листа и веток
   граничного дерева строятся по шаблону без проверки препятствий. Им
   достаётся тот же перебор, что уже есть у обратных связей и входов с края
   (`pick`, `lanes`), с запасным вариантом через коридор над или под
   лестницей. Этот вариант чист всегда — доказательство в research И2, — и
   «названной границы» для собственной лестницы нет.
2. **Авто-блоки обходят авторские.** Налезающий авто-блок сдвигается за
   авторский с зазором 24; не налезающий — не двигается.
3. **Предупреждение об авторской стрелке сквозь блок.** Новая последняя
   ступень `validate.Build`: раскладка (только без ошибок) и проверка
   геометрии. Так предупреждение одно и то же в `validate` и в компиляции и
   проверяется эталоном.

## Порядок работ

1. **Мера до.** `through.py` на всём наборе: 2 и 5; отпечатки файлов.
2. **Красный тест.** `TestNoArrowThroughBlock` по собранному файлу — красный на
   «чахохбили» и `skirt-full`.
3. **Обходчик.** Кандидаты и коридоры в `route.go`; `forward` и выход к краю
   через него. Проверка: `TestForwardRouteMatchesRamus` и
   `TestStaircaseMatchesRamus` без правки чисел — чистые шаблоны не тронуты.
4. **Дерево.** Ветки граничного дерева через обходчик.
5. **Авто-блоки.** Сдвиг за авторские; `skirt-full` — ноль перекрытий.
6. **Ступень геометрии.** Раскладка в `validate.Build`, `geometry.go`, код,
   модель, эталон; `cmd` — без двойной раскладки или с проверенной
   идемпотентностью.
7. **Охрана.** `make check`; побайтово меняются только «чахохбили» и
   `skirt-full`; `overlapDocuments` удалён.
8. **Документация.** `CLAUDE.md`, `RSF-FORMAT.md` не требуется.
9. **Взгляд в Ramus.**

## Риски и их снятие

| Риск | Снятие |
|---|---|
| Обход меняет маршруты, которые никого не задевали | прежний шаблон — первый кандидат; побайтовое сравнение набора; `TestForwardRouteMatchesRamus` без правки |
| Сдвиг авто-блока отцепляет авторскую стрелку от блока | на `skirt-full` ветка «Правил изготовления» остаётся над верхом сдвинутого блока (research И3); в общем случае — авторская точка не меняется по Р2, и это видно глазами, а не молча |
| `validate` становится медленнее для GUI | раскладка — миллисекунды; валидация и так по действию, а не на каждый символ |
| Раскладка в `validate` ломает лесенку | запускается только без ошибок; ступень геометрии выдаёт лишь предупреждения |
| Каналы после обхода заводят стрелку в блок | каналы уже отвергают такой сдвиг; `TestNoArrowThroughBlock` по собранному файлу поймает, если нет |
| Авторские блоки вплотную — чистого пути нет | названная граница FR-005; тест называет стрелку поимённо |
| `CLAUDE.md` не в git | правка руками отдельной задачей |
