# Quickstart: проверка разведения по каналам

Как убедиться, что фича работает, и как воспроизвести измерения, на которых
построен план.

## Предварительно

```bash
cd ramusc && make build     # даст ./ramusc/ramusc
```

Внешнего ничего не нужно: Go 1.26 и три зависимости уже в модуле. Ramus для
проверки **не требуется** — наложение выражается координатами и меряется по
собранному файлу.

## 1. Измерить наложения на любой модели

Круг измерения: документ → `.rsf` → обратно в JSON → счётчик наложений.

```bash
./ramusc/ramusc <документ.yaml> -o /tmp/m.rsf
./ramusc/ramusc decompile /tmp/m.rsf --json > /tmp/m.json
python3 specs/009-no-segment-overlap/evidence/overlap.py /tmp/m.json
```

Скрипт печатает по строке на пару наложившихся сегментов: диаграмму,
ориентацию, координату, оба потока и длину общей части.

Скрипт — инструмент сверки, а не часть поставки: он читает тот же результат,
что и тест, но снаружи компилятора, и потому ловит расхождение между тем, что
раскладка думает, и тем, что доехало до файла. Тот же приём, что у `dump`
против `algodemo/rsf.py`.

**Ожидаемо до фичи**: `examples/chakhokhbili.yaml` даёт 25 наложений,
`probe-pair`, `probe-feedback` и `probe-trunk` — 1, 7 и 6.
**Ожидаемо после**: ноль на всех документах набора и на всех пробах.

Рядом лежит второй счётчик — `evidence/crossing.py`, он считает сегменты,
проходящие **сквозь блок**. Это другой дефект, вне объёма этой фичи
(research.md, «Находка вне объёма»), и чинить его здесь не нужно. Счётчик
приложен, чтобы находка не потерялась: сегодня он показывает 1 на
`chakhokhbili` и 1 на `probe-skip.yaml`.

## 2. Прогнать весь набор разом

```bash
for f in ramusc/testdata/documents/*.yaml examples/skirt.yaml; do
  n=$(basename "$f" .yaml)
  ./ramusc/ramusc "$f" -o "/tmp/$n.rsf" >/dev/null
  ./ramusc/ramusc decompile "/tmp/$n.rsf" --json > "/tmp/$n.json"
done
python3 specs/009-no-segment-overlap/evidence/overlap.py /tmp/*.json
```

Итоговый вид — ноль наложений в каждой строке.

## 3. Тесты

```bash
cd ramusc && make check      # форматирование, go vet, все тесты
go test ./internal/layout/   # только раскладка
```

Проверки, добавленные фичей:

| Тест | Что требует |
|---|---|
| `TestNoSegmentOverlap` | ни одной пары сегментов разных стрелок с общей частью ненулевой длины |
| `TestChannelsAreStable` | две раскладки одного документа дают побитово равные координаты |
| `TestSingleClaimUnmoved` | когда претендент на линию один, координата не изменилась |

**Порядок работ обратный обычному**: фикстуры пишутся первыми. На сегодняшнем
наборе `TestNoSegmentOverlap` проходит и на непочиненном коде (research.md,
измерение 1) — тест, который не краснеет, ничего не доказывает.

## 4. Убедиться, что ничего не сломалось

```bash
cd ramusc && go test ./...            # весь круг: разбор, генерация, декомпиляция
git diff --stat ramusc/testdata/golden/   # обязано быть пусто
```

Эталоны сняты с файла самого Ramus, разведение их не касается. Поехавший
эталон — признак, что проход тронул лишнее (contracts/channels.md, §6).

## 5. Глазами (необязательно, но полезно)

```bash
./ramusc/ramusc specs/009-no-segment-overlap/evidence/probe-feedback.yaml -o /tmp/p.rsf
```

Открыть `/tmp/p.rsf` в Ramus. До фичи четыре обратные связи видны как две
линии, после — как четыре. Автоматической эта проверка не станет: Ramus —
внешняя программа с GUI. Она подтверждает результат, но не заменяет пункт 3.
