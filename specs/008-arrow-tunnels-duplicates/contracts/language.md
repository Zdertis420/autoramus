# Контракт: входной язык

Одно новое поле и одно уточнённое правило. Оба — совместимые: документ, который
компилировался раньше, компилируется и теперь, кроме случаев, где он молча терял
стрелки (в том и смысл фичи).

## 1. `tunnel` у работы — новое поле

```json
"function": {
  "properties": {
    "tunnel": {
      "description": "Потоки, которые намеренно не переходят в декомпозицию этой работы: конец стрелки на родительской диаграмме рисуется в скобках.",
      "$ref": "#/$defs/flowList"
    }
  }
}
```

| Свойство | Значение |
|---|---|
| Обязательность | нет; отсутствие равно пустому списку |
| Тип | `flowList` — тот же, что у `in`, `control`, `mechanism`, `out` |
| Проверки | каждое имя объявлено в `flows` (`unknown_flow`); каждое имя есть среди ICOM той же работы; повтор внутри списка — ошибка |
| Действие | поток из списка снимается с проверки «дошёл ли ICOM до декомпозиции» |

Пример — `examples/skirt-full.yaml` после правки:

```yaml
- name: Приём заказа
  of: Изготовление юбки
  kind: dfd
  in:        [Заявка]
  control:   [Регламент приёма]
  mechanism: [Менеджер]
  out:       [Заявка в работе]
  tunnel:    [Регламент приёма, Менеджер]
```

**Не путать** с `tunnel: true` у конца сегмента в `layout.arrows`: то —
часть геометрии, это — утверждение о модели. Подробнее — `data-model.md`, §2.

## 2. `layout.arrows` — гранулярность оверрайда

**Было**: автор описал поток — раскладка не трогает его **нигде** в модели.

**Стало**: автор описал поток — раскладка не трогает его **на тех диаграммах,
где есть хоть один его сегмент**, и рисует как обычно на всех остальных.

| Что | Было | Стало |
|---|---|---|
| Единица оверрайда | поток | поток + диаграмма |
| Сегменты того же потока на других диаграммах | исчезали из файла молча | дорисовывает раскладка |
| Связь на переопределённой диаграмме, не покрытая ни одним сегментом | исчезала молча | ошибка `incomplete_arrow_layout` |
| Координаты, заданные автором | не менялись | не меняются |

Порядок записей в `layout.arrows` и порядок сегментов внутри стрелки автор задаёт
сам; раскладка дописывает недостающее **после** авторского, сохраняя его индексы.
Этого требует Р2 и принцип III: правка документа не должна перетасовывать то,
чего автор не трогал.

## 3. Совместимость

| Документ | Было | Стало |
|---|---|---|
| Без `layout.arrows` | компилируется | без изменений |
| С `layout.arrows`, покрывающим все связи потока на своих диаграммах | компилируется, теряя стрелку на прочих диаграммах | компилируется полностью |
| С `layout.arrows`, покрывающим не все связи на своей диаграмме | компилируется, теряя непокрытые | `incomplete_arrow_layout` |
| С дублем ICOM + `links` | два сектора, молча | один сектор, `duplicate_link` уровня `warning` |
| С DFD-декомпозицией, куда не доходит ICOM | компилируется, туннели молча | `flow_not_decomposed`, снимается полем `tunnel` |

Третья и четвёртая строки — единственные, где документ, проходивший раньше,
перестаёт проходить. Оба случая означают, что из файла и раньше пропадала
стрелка, просто без сообщения.

**Затронутые примеры репозитория**: `examples/skirt-full.yaml` — добавляется
`tunnel: [Регламент приёма, Менеджер]` у «Приёма заказа» и дописываются сегменты
«Правил изготовления» до полного покрытия A0 либо убирается их оверрайд.
Документ заявлен образцом, проходящим без замечаний, и обязан им остаться.
