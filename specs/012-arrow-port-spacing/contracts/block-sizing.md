# Контракт: размер блока от числа стрелок

## 1. Внешние интерфейсы не меняются

| Поверхность | Изменение |
|---|---|
| CLI `ramusc`: команды, флаги, коды возврата | нет |
| `--json` диагностики, коды `internal/diag` | нет |
| Входной язык, `model.schema.json` | нет |
| IR (`internal/ir`) | нет |
| Таблицы, колонки и последовательности `.rsf` | нет |
| `layout.Apply(m *ir.Model)` | подпись та же |
| `internal/generate` | не трогается |

Меняются **значения**: `width`/`height` блоков, которым тесно, `x`/`y` блоков
на диаграммах, где кто-то вырос, и маршруты стрелок на этих диаграммах.

## 2. Правило размера

```go
// portGap — наименьший промежуток между соседними стрелками одной стороны.
// Решение, а не мера: авто-раскладка Ramus не ставит теснее 16.8, в правленных
// руками моделях теснее 15 — 2 промежутка из 27; ровно 15 Ramus не ставит
// нигде (specs/012-arrow-port-spacing).
const portGap = 15.0
```

| Сторона | Растит | Нужно |
|---|---|---|
| вход, выход | высоту | `(max(входов, выходов) + 1) · portGap` |
| управление, механизм | ширину | `(max(управлений, механизмов) + 1) · portGap` |

Размер — наибольшее из нужного и базового. Базовый — сегодняшний, со сжатием с
десяти работ.

## 3. Правило лестницы

Для диаграммы из n ≥ 2 блоков в порядке `sortByFlow`, с автоматическими
размерами `w_i × h_i` и сегодняшними `stepX`, `stepY`, базовыми `w`, `h`:

```
gx = max(gap, ((n−1)·stepX + w − Σ w_i) / (n−1))
gy =          ((n−1)·stepY + h − Σ h_i) / (n−1)

x_0 = 80,  x_{i+1} = x_i + w_i + gx
y_0 = 80,  y_{i+1} = y_i + max(gap, h_i + gy)
```

При равных размерах `x_i = 80 + i·stepX`, `y_i = 80 + i·stepY` — сегодняшняя
лестница. n = 1 — центр листа, размер по правилу §2.

## 4. Авторская геометрия

| Автор задал | Раскладка |
|---|---|
| `x`, `y`, `width`, `height` | не трогает ничего |
| `x`, `y` | дописывает `width`, `height` по §2 |
| ничего | всё по §2 и §3 |

В суммах §3 каждый блок участвует автоматическим размером, задал его автор или
нет: закрепление соседа не двигает остальных (`TestPartialOverride`).

## 5. Маршрут «выход → управление»

| Условие | Маршрут |
|---|---|
| точка выхода источника выше верха приёмника хотя бы на `stub` | прежний: вправо до вертикали порта, вниз в порт |
| иначе | вправо до середины промежутка, вверх до `верх приёмника − stub`, вправо до вертикали порта, вниз в порт |

## 6. Инварианты, которые проверяются тестами

Новые:

| Инвариант | Тест | Где |
|---|---|---|
| промежуток на стороне ≥ 15 по собранному файлу, на всём наборе, кроме блоков с авторским размером | `TestPortSpacing` | `generate` |
| мера: авто-раскладка Ramus (`тест.rsf`) не теснее 15; только этот файл — в `ФормированиеТП.rsf` три входа на 50.4 дают 12.6 | `TestPortSpacingInRamusFiles` | `generate` |
| рост только по нужной оси; без тесноты — 72 × 50.4 | `TestBlockGrowsAlongCrowdedSide` | `layout` |
| выросшие блоки не пересекаются, лестница возрастает, всё внутри листа | `TestGrownLadder` | `layout` |
| равные размеры дают сегодняшнюю лестницу до знака | `TestDiagonalForThree`, `TestMatchesRamus` (без правки) | `layout` |
| `x`/`y` без размера — размер дописан, не ноль | `TestPartialOverrideFillsSize` | `layout` |
| «выход → управление» при перекрытии не идёт сквозь приёмник | `TestControlRouteClimbsOver` | `layout` |

Обязаны уцелеть без правки:

| Инвариант | Тест |
|---|---|
| сегменты разных стрелок не накладываются | `TestNoSegmentOverlap` |
| стрелка не идёт сквозь блок и не наискось | `TestGeometryIsLawful` |
| форма дерева, узел — одна точка | `TestTreeShape`, `TestTreeNodesAreOnePoint`, `TestCrosspointIsOnePoint` |
| каждая связь нарисована | `TestEveryLinkDrawn` |
| общие ординаты в узлах | `TestJunctionEndsShareOrdinates` |
| закрепление соседа не двигает остальных | `TestPartialOverride` |
| две сборки — один файл | `TestDeterministic`, `TestDeterministicWithArrows` |
| круг «документ → файл → документ» | `TestRoundTrip` |

Тесты пакета `layout` — чёрный ящик (`package layout_test`) и зовут только
`layout.Apply`, поэтому смена сигнатуры `place()` их не задевает. Модели из
помощника `model()` без связей: спрос нулевой, размеры базовые, числа прежние.
