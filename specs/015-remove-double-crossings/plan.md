# Implementation Plan: Без ненужных двойных пересечений

**Branch**: `Минимальное-расстояние-между-стрелками` | **Date**: 2026-09-26 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/015-remove-double-crossings/spec.md`

## Summary

Лишнее двойное пересечение рождается в одном месте — `pickLane` в разведении
по каналам: заявка, которой канон занят, отходит на `+шаг` просто потому, что
`+` стоит в списке первым, не глядя, что с `−шаг` она не пересекла бы соседку.

Правка одна: на каждом шаге сравнить обе свободные стороны числом
пересечений и взять меньшее; при равенстве — `+шаг`, как прежде. Прототип
(research И2) снял обе лишние пары набора, на «чахохбили» 158 → 156
пересечений, `channels-pair` 2 → 0, `channels-trunk` 5 → 4; одиннадцать
документов побайтово те же; ни один не стал хуже.

## Порядок работ

1. **Мера до.** `swap.py`, `double.py`; отпечатки файлов.
2. **Красные тесты.** `TestNoAvoidableDoubleCrossing` — красный на
   «чахохбили» и `channels-pair`; `TestCrossingsDoNotGrow` — зелёный сразу
   (потолки сняты с сегодняшнего состояния).
3. **Правка `pickLane`.** Стрелки диаграммы — в `spread`; сравнение сторон.
4. **`TestCanonicalLaneKept`.** Ожидание «второго» — `канон − шаг`, с
   комментарием, почему направление не было правилом.
5. **Охрана.** `make check`; побайтово изменились ровно три документа;
   `swap.py` — ноль лишних пар.
6. **Документация.** `CLAUDE.md`.
7. **Взгляд в Ramus.**

## Риски и их снятие

| Риск | Снятие |
|---|---|
| Выбор по пересечениям где-то добавит пересечения третьей стрелке | считается пересечение со **всеми** стрелками диаграммы, а не с одной соседкой; `TestCrossingsDoNotGrow` на всём наборе |
| Счёт в тесте разойдётся со счётом скрипта, и потолки окажутся не теми | тест считает ровно как `double.py` (различные точки, строгие неравенства); потолки сверяются прогоном на состоянии «до» — тест обязан быть зелёным до правки |
| Правка теста `TestCanonicalLaneKept` спрячет регрессию | правится только направление; «первый на каноне» и «ровно один шаг» остаются |
| `CLAUDE.md` не в git | правка руками отдельной задачей |
