# Data Model: Подписи стрелок не налезают друг на друга

Новых сущностей во входном языке, в IR и в файле нет. Меняются значения
`TEXT_X`, `TEXT_Y`, `TEXT_WIDTH`, `TEXT_HIEGHT` в строках
`attribute_sector_properties` у показанных подписей. Кто подписан (`SHOW_TEXT`,
`TRANSPARENT`) — не меняется. Всё ниже — внутренние величины пакета
`internal/generate`.

## Ширина текста

| Что | Правило |
|---|---|
| ширина знака | по таблице `glyphs.go`: наибольшая из Dialog 8 и Liberation Sans 8 |
| знак вне таблицы | ширина самого широкого знака таблицы |
| ширина строки | сумма ширин знаков |
| высота строки | 9.80078125 (`sectorLineHeight`, мера файлов Ramus) |

## Раскладка подписи

Одно из возможных разбиений имени на строки.

| Поле | Смысл |
|---|---|
| строки | слова имени, разбитые по пробелам и после дефиса, как у Ramus |
| ширина | ширина самой широкой строки |
| высота | число строк × высота строки |

* Первая раскладка — одна строка; каждая следующая — на строку больше, с
  наименьшей возможной шириной самой широкой строки.
* Ширина любой раскладки не меньше самого длинного слова: Ramus не перенесёт
  внутри слова (research И3).
* Раскладок не больше, чем слов.

## Кандидат

Рамка подписи в одном из допустимых мест.

| Поле | Смысл |
|---|---|
| отрезок | прямой отрезок подписанного сектора, у которого стоит рамка |
| сторона | над / под (горизонталь), слева / справа (вертикаль) |
| сдвиг | положение вдоль отрезка: середина, затем от неё к краям |
| раскладка | см. выше |
| рамка | x, y, ширина, высота |

* Отступ от своей линии — `labelGap = 3` (research И4).
* Порядок кандидатов фиксирован (research Р-3), и он же — порядок
  предпочтения при равенстве.

## Препятствия диаграммы

| Препятствие | Вид |
|---|---|
| поставленные подписи | жёсткое |
| блоки работ | жёсткое |
| край листа | жёсткое |
| отрезки чужих стрелок | мягкое |

«Чужая» — стрелка другого потока. Свои отрезки препятствием не считаются:
подпись по определению стоит рядом с ними.

## Выбор

1. Кандидаты без жёстких препятствий в пределах 34 от своей линии — берётся
   тот, что пересекает меньше всего чужих отрезков; при равенстве — первый.
2. Таких нет — названная граница (FR-012): кандидат с наименьшей площадью
   жёсткого наложения, затем с наименьшим числом мягких.

Подписи одной диаграммы ставятся по одной, в порядке стрелок документа
(research Р-5); поставленная подпись становится препятствием для следующих.

## Инварианты

| Инвариант | Откуда |
|---|---|
| рамки подписей диаграммы не пересекаются, кроме названной границы | FR-001, FR-012 |
| рамка не заходит на блок, кроме названной границы | FR-002, FR-012 |
| рамка внутри листа | FR-003 |
| до своей линии не дальше 34 | FR-004 |
| ширина не меньше самого длинного слова | FR-005 |
| подписан тот же сектор, что и прежде | FR-008 |
| геометрия стрелок и блоков не меняется | FR-009 |
